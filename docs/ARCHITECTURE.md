# 架构边界与渐进整理

本次整理将设备业务移出 `main.dart`，保留现有 Material / BLoC 页面结构，后续按模块逐步迁移。

## 调用路径

页面 → 业务 Cubit / 服务 → DeviceSession / CommandRunner → ToolProcess → 私有运行环境。

- `DeviceConnectionCubit` 持有设备列表、选中设备、信息、包名查询和扫描状态，刷新和查询使用请求序号，切换使用独立取消标记。旧设备的迟到结果不能写入当前状态。
- `DeviceInfoService` 对固定的 DeviceSession 连续读取设备字段，格式不支持时返回“未知”，不伪造容量或设备数据。
- `CommandRunner` 是短命令统一入口，管理输出编码、非零退出码和取消，可注入执行器进行测试。默认执行仍经 `tool_process.dart`。
- `DeviceSession` 固定设备标识并绑定参数，禁止自定义命令覆盖设备选择、停止共享 ADB 服务。设备列表、连接及配对等全局操作有明确白名单。
- `MirrorSession` 持有单个 scrcpy 进程和输出流，控制启动、停止和释放；长时间投屏不交给短命令收集器。
- 文件传输和截图等专用服务通过 ToolProcess 管理自己的进程；流式传输与二进制截图保留专用处理，避免为形式统一而丢失数据或进度。
- `AdbProcessDataSource` 只处理真实设备读取与解析，演示数据源不作为设备故障后的自动回退。
- `AppOutput` 按任务追加有长度上限的日志；页面订阅日志而不另存一份无限增长的输出。

## 生命周期与所有权

业务状态和服务关闭时取消所属任务，页面异步返回前检查 mounted。设备切换取消信息读取和包名查询；页面按设备 key 重建文件、截图和监控模块；批量任务关闭后不启动下一项。

AdbHomePage 默认创建并释放 DeviceConnectionCubit 与 MirrorSession。测试或宿主显式注入的实例由调用者负责释放；页面仍解除自己的订阅。控制器在状态初始化时创建，在 dispose 释放，避免 build 中反复分配。

CommandRunner 的测试执行器接收独立参数列表和取消对象。生产默认入口才负责启动真实进程、超时和终止；测试执行器必须自己模拟完成/取消，不能据此声称真实设备性能或稳定性已验收。

## 后续边界

`main.dart` 仍承担导航、设置回调和页面组装；设置持久化与投屏偏好仍可进一步迁移到独立 Cubit。业务页面尚未全部采用统一 BLoC，此次没有进行全仓重写。新增业务优先进入对应模块，并复用设备会话、取消和日志入口。发布脚本与运行环境安装保持独立于 UI 的回归测试。
