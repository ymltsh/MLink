# 测试与真机验收

普通自动化测试不操作真实 Android 设备。第 1–4 阶段的业务回归使用可注入命令、进程、套接字和临时文件，验证参数、流、状态和界面接线；其结论不包含厂商兼容性和真机投屏效果。

## 自动化覆盖

| 范围 | 用例与证据 |
| --- | --- |
| 上传/下载 | `phase_one_test.dart`：实时进度、成功/失败结束、尾部输出、取消与启动中释放；特殊远端名称参数转义 |
| 文件浏览和状态 | `phase_two_test.dart`：真实元数据、符号链接、空目录与权限错误区分、过期结果、批量关闭、失败重试、Root 传输拒绝 |
| 设备目标与监控 | 第 1、4 阶段：双设备明确参数、读取失败不自动使用 Mock、org 包名前台识别、刷新掉线清空状态 |
| 设备竞争与退出 | `phase_four_test.dart`：A→B→A 迟到结果、最新包名查询优先、关闭后不继续读取 |
| 扫描 | 第 2 阶段：并发上限、指定端口、取消不继续调度、实际本地套接字关闭 |
| 投屏与界面 | 第 2、4 阶段：配置校验、真实主页面选择设备/读取偏好/启动停止、设置命令目标、重复启动和启动中取消 |
| 截图 | 第 2 阶段：失败停止定时器、关闭后不加载历史 |
| 工具与更新 | 工具环境、更新服务及第 3 阶段：摘要、归档路径、缓存恢复、相同版本复用、官方摘要直连、租约和回收、数值版本比较与更新交互 |
| 发布 | `tests/`：构建号递增、预发布隔离、无副作用预览、检查记录、源码指纹及复用产物校验 |

`tool_environment_smoke_test.dart` 默认跳过，设置 `MLINK_TOOLS_SMOKE=1` 才执行真实网络下载和可执行文件版本检查。它不是真机业务测试。

## 本地检查

```powershell
flutter pub get
dart format <本次涉及的 Dart 文件>
flutter analyze
flutter test
python -m unittest discover -s tests
python release.py --version 1.0.1 --build 2 --dry-run
```

不要为使检查通过删除分析规则或默认跳过失败用例。`file_picker` 桌面插件声明提示属于现有依赖问题，须与分析/测试结果同时说明。

## 待执行的真机验收

以下项目本轮**未执行**。在专用测试设备与临时目录完成，记录设备 Android 版本、工具 tag、应用版本和结果，日志不提交设备标识。

1. **双设备与退出**：连接两台已授权设备，在 A/B 间切换并查询信息、包名、进程；确认命令仅影响选中设备，旧结果不回填。读取时拔线或关闭页面，确认有错误提示且无持续轮询。
2. **文件完整性**：在测试目录准备中文、空格、单引号、美元符号、分号和换行名称及符号链接；上传/下载后比较 SHA256，核对类型、时间。对无权限目录操作应失败，恢复授权后可重试；关闭页面后不启动批量下一项。仅删除本次创建的测试文件。
3. **投屏与截图**：验证默认/临时画质、关闭设备屏幕、禁用音频及停止/再启动；真机支持时验证单应用虚拟显示与 DPI。截图/定时截图时拔线与离开页面，确认任务收敛。
4. **网络与运行环境**：验证无线配对和连接端口不同、扫描取消、断网重试、重复更新不重复下载，旧投屏运行时更新环境不破坏旧会话。
5. **发行包**：具备 Visual Studio C++ 与 Inno Setup 6 的 Windows x64 环境中构建本地安装包及便携包，在干净系统安装/卸载并验证 LICENSE、首次补全和离线重开。实际上传与远端 CI 另外验收。

macOS/Linux 和 Android APK 均未获得正式发行验收；Android 仍为调试签名，不能作为手机正式发行物。
